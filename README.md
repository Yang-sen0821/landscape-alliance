# 台灣景觀聯盟 — 部署與設定指南

## 第一步：建立 Google Sheets

1. 開一個新的 Google 試算表
2. 第一行（標題列）填入以下欄位：

| A | B | C | D | E | F | G | H | I | J | K |
|---|---|---|---|---|---|---|---|---|---|---|
| 姓名 | 公司名稱 | 地區 | 行業別 | 照片1 | 照片2 | 照片3 | 照片4 | 照片5 | 標籤 | 顯示 |

3. **照片欄位**：將照片上傳到 Google Drive，右鍵 → 取得連結 → 「知道連結的人」，
   將 URL 轉換為直接預覽格式：
   - 原始：`https://drive.google.com/file/d/FILE_ID/view`
   - 轉換：`https://drive.google.com/uc?export=view&id=FILE_ID`

4. **標籤欄位（J欄）**：用逗號分隔，從以下選項選填：
   - 坪數：`10坪以下` / `10-30坪` / `30-100坪` / `100坪以上`
   - 環境：`庭院` / `室內` / `屋頂花園` / `商業空間` / `公共工程`
   - 風格：`日式` / `現代簡約` / `熱帶風` / `地中海` / `台式傳統`
   - 元素：`喬木` / `灌木` / `仿生植物` / `水景` / `石材` / `花卉`
   - 預算：`5萬以下` / `5-15萬` / `15-50萬` / `50萬以上`
   - 範例：`庭院,日式,水景,石材,10-30坪,15-50萬`

5. **顯示欄位（K欄）**：填 `是` 顯示 / `否` 隱藏

6. 設定公開：「共用」→「知道連結的人」→「檢視者」

7. 複製網址列的 Sheet ID（網址中 `/d/` 和 `/edit` 之間的那段）

---

## 第二步：設定網站

開啟 `js/app.js`，修改第8行：

```js
const SHEETS_ID = '你的_Sheet_ID'; // 貼上剛才複製的 ID
```

如果有 Google Form 申請連結，也填入：

```js
const JOIN_FORM_URL = '你的_Google_Form_網址';
```

## 第三步：建立 Google Form（成員申請表）

欄位：
1. 姓名（簡答）
2. 公司名稱（簡答）
3. 服務地區（簡答）
4. 行業別（下拉選單）
5. 作品照片（最多5張）
6. 坪數 tag（核取方塊）
7. 環境 tag（核取方塊）
8. 風格 tag（核取方塊）
9. 元素 tag（核取方塊）
10. 參考預算區間（單選）

---

## 第四步：部署到 GitHub Pages

### 方法 A：GitHub Pages（需要 GitHub 帳號）
1. 到 github.com 建立帳號（免費）
2. 新增 Repository，名稱：`landscape-alliance`
3. 上傳全部檔案（index.html / css / js）
4. Settings → Pages → Source: main branch
5. 網址：`https://你的帳號.github.io/landscape-alliance`

### 方法 B：Netlify（更簡單，不需要 GitHub）
1. 到 netlify.com 建立帳號（免費）
2. 主頁面直接「拖放資料夾」到 Deploy 區
3. 拖放 `F:\landscape-alliance\` 整個資料夾
4. 10秒後取得網址（可自訂）
